# Personal Portfolio Website

A full-stack personal portfolio website built to showcase my skills, projects, internships, and contact information.

## About

This portfolio was developed using Flask for the backend, HTML/CSS/JavaScript for the frontend, and SQLite for database management.

## Features

* Responsive personal portfolio website
* Navigation between different sections
* About Me section
* Technical skills section
* Dynamic project cards loaded from SQLite
* Internship and experience section
* Contact form connected to Flask backend
* Contact messages stored in SQLite database
* GitHub and LinkedIn profile links
* Responsive design for different screen sizes
* Dynamic footer year using JavaScript

## Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python, Flask
* **Database:** SQLite
* **Tools:** VS Code, Git, GitHub

## How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/ashwithathaluri06-ai/personal-portfolio.git
```

### 2. Open the project folder

```bash
cd personal-portfolio
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows PowerShell:**

```powershell
venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python app.py
```

Then open:

```text
http://127.0.0.1:5000/
```
