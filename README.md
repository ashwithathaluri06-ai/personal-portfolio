# Personal Portfolio Website

A full-stack personal portfolio website built using Flask, HTML, CSS, JavaScript and SQLite.

## About

This portfolio showcases my skills, projects, internship experience and provides a contact form for communication.

## Features

- Responsive personal portfolio website
- Home, About, Skills, Projects and Internships sections
- Dynamic projects loaded from SQLite database
- Contact form connected to Flask backend
- Contact messages stored in SQLite database
- GitHub and LinkedIn profile links
- Responsive design for different screen sizes
